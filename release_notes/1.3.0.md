# LittleHorse 1.3.0

LittleHorse 1.3.0 brings the JavaScript/TypeScript SDK to broad feature parity with the Java SDK, adds queued thread execution to protect workflows from excessive concurrency, and expands the Map and Struct authoring experience across SDKs and the dashboard. This release also adds quota usage metrics, improves workflow migration discovery, lets callers choose child `WfRun` IDs, and moves partition-local maintenance work onto a dedicated background scheduler for more reliable server operation.

## Features

### Server

- Added a per-`WfRun` thread queue. When a workflow reaches its configured active `ThreadRun` limit, additional threads are queued instead of failing the run; completed thread details can also be archived to bound the active run state. #2379
- Added inline Map construction and Map mutation support, including key-based `put` operations and Map comparisons in `WfSpec` conditions. #2442, #2443
- Struct variables can now evolve to newer compatible `StructDef` versions without requiring every referencing `WfSpec` to be updated first. #2487
- `StructFieldDef` fields can now include descriptions, with support across the server, SDK annotations, generated types, and dashboard forms. #2485
- Callers can provide a deterministic ID when starting a child `WfRun`, making child workflows easier to address and integrate with external identifiers. #2502
- Added gRPC-facing quota usage metrics and `lhctl` support for inspecting quota consumption by tenant and time window. #2467
- Added `SearchWorkflowMigrationPlan` and corresponding `lhctl` support, making workflow migration plans discoverable through the API and CLI. #2461
- Replaced Kafka Streams punctuators used for partition-local maintenance with a dedicated background scheduler. Timer scans, bulk deletion, metrics catch-up, and tenant rehydration now run incrementally without blocking stream processing. #2495

### JavaScript/TypeScript SDK

- Added a full workflow authoring SDK with variables, expressions, control flow, child threads and workflows, events, user tasks, mutations, retries, retention policies, and Struct/Map builders. #2500
- Expanded task worker support with typed serialization, custom type adapters, OAuth configuration, worker context, user-task helpers, and broader registration APIs. #2500
- Added an extensive set of runnable JavaScript examples covering core workflow patterns and an integration suite for execution, workers, OAuth, TLS, and workflow constructs. #2500
- Introduced a cross-SDK conformance suite that compares Java and JavaScript behavior for workflow generation, registration, and serialization. #2500

### Java SDK

- Added `LHMapBuilder` and Map `put` operations for constructing and mutating Map values directly in workflows. #2443
- Struct placeholder templates now support default field values. #2450

### Dashboard

- Upgraded the dashboard to Next.js 16 and React 19. #2419
- Improved Struct input forms to display field descriptions and type information. #2485
- Child workflow nodes now use a distinct box shape, making workflow diagrams easier to read. #2470

## Performance And Reliability

- Bulk `WfRun` deletion now warms the RocksDB block cache before forwarding delete commands and performs fewer cold reads. #2473, #2506
- Failed `ReportTaskRun` commands are retried when stream processing fails, while producer-level failures such as oversized records return an appropriate gRPC error. #2429, #2435

## Bug Fixes

### Server

- StructDef descriptions can now be updated, and updates correctly bump the StructDef version. #2452, #2454
- Edge compare expressions are evaluated against buffered mutations, preventing out-of-order mutation results. #2448
- The metadata cache now uses bounded LRU eviction to prevent unbounded memory growth. #2397
- Micrometer counters are cached in `CommandProcessorMetrics`, reducing metrics overhead on the hot path. #2453

### Dashboard

- Ending a dashboard session now also ends the Keycloak session. #2481
- Required variables are enforced when executing a `WfSpec`. #2460
- `WfRun` diagrams now open on the entrypoint `ThreadRun`. #2463
- Prevented the sidebar from crashing when polling leaves a stale `NodeRun` or attempt selection. #2447
- Large `ListVariables` responses that exceed the gRPC message limit are handled gracefully. #2418
- Added a clipboard copy fallback for environments where the Clipboard API is unavailable. #2401
- Optional variables are now sent when executing a `WfSpec`. #2445
- Fixed tenant dropdown overpopulation. #2434
- Node selection and viewport are preserved across `WfRun` polling refreshes. #2423

### SDKs

- Java SDK: task workers now throw a descriptive exception when ingesting nulls into primitive fields during `PollTask` serialization. #2457
