# LittleHorse 1.3.2

LittleHorse 1.3.2 is a focused patch release that updates Guava and corrects its dependency declaration in the Java SDK.

## Bug Fixes

### SDKs

- Java SDK: Guava is now declared directly as an API dependency because generated gRPC future stubs expose Guava types. The shared Guava version has been upgraded from `33.4.8-jre` to `33.7.2-jre`. #2606
