# LittleHorse 1.2.1
The LittleHorse v1.2.1 release is a patch focused on stability and correctness. It fixes StructDef description updates on the server, resolves several dashboard usability issues, and improves server memory management and metrics performance.

## Fixes

### Server
- StructDef descriptions can now be updated, and upon updating will bump the StructDef version. #2452, #2454
- Edge compare expressions are now evaluated against buffered mutations, fixing a bug where some mutations were processed out of order. #2448
- The metadata cache is now bounded with an LRU eviction policy, preventing unbounded memory growth. #2397
- Micrometer counters are cached in CommandProcessorMetrics, reducing metrics overhead on the hot path. #2453

### Dashboard
- Added a clipboard copy fallback for environments where the clipboard API is unavailable. #2401
- Optional variables are now sent when executing a WfSpec. #2445
- Fixed tenant dropdown overpopulation. #2434
- Node selection and viewport are now preserved across WfRun polling refreshes. #2423

### SDKs
- Java SDK: Task Workers now throw a descriptive exception when ingesting nulls to primitive fields during PollTask serialization. #2457
