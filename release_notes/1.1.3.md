# LittleHorse 1.1.3

LittleHorse 1.1.3 improves server recovery and resilience with a Kafka upgrade, transactional state stores, and shorter Kafka request timeouts during broker restarts. This patch also updates Guava and improves release publishing reliability.

## Server

- Upgraded Kafka clients and Kafka Streams from `4.2.0` to `4.4.0`, adding support for transactional state stores to reduce state restoration after unclean shutdowns. #2591
- Enabled transactional state stores by default for the core topology. Operators can disable them with `LHS_CORE_KS_CONFIG_ENABLE_TRANSACTIONAL_STATESTORES=false`. Core interactive queries use `READ_UNCOMMITTED` isolation to preserve read-your-own-writes consistency. #2661
- Reduced the Kafka request timeout from 75% to 30% of the configured Streams session timeout, allowing more retries before a transaction times out during rolling broker restarts. #2526
- Added startup error logging that identifies the configured state directory when Kafka Streams fails to initialize persisted state, helping diagnose incompatibilities after downgrading versions.

## Dependencies

- Upgraded the shared Guava dependency used by the server and Java SDK from `33.4.8-jre` to `33.7.2-jre`. #2591
